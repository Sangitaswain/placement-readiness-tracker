# Runner-up Score Test Cases

Each test reads n on the first line and n integer scores on the second line. The program prints only the second-highest distinct score.

| Case | n | Scores | Expected output | Actual output |
| --- | --- | --- | --- | --- |
| Highest score repeated | 5 | 55 100 100 70 90 | 90 | 90 |
| Zero and duplicates | 4 | 0 20 20 20 | 0 | 0 |
| Minimum input size | 2 | 20 50 | 20 | 20 |

Case 1 includes a repeated highest score. Case 2 includes zero and duplicates. Case 3 uses the minimum permitted n of 2.
